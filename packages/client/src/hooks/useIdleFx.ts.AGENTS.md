# useIdleFx.ts — index

`useIdleFx()` — 5000 ms (`IDLE_FX_DELAY_MS`) input-idle detector; toggles `fx-idle` on `document.documentElement` (capture-phase pointerdown/wheel/keydown/touchstart/focusin/focus — deliberately NOT pointermove/scroll: resting-hand micro-moves + streaming auto-scroll events would hold the FX alive all stream; any counted input clears + re-arms). CSS `:root.fx-idle *` pauses ALL animations (wildcard, mirrors `app-hidden`) — idle windows measured 1423 ms GPU-main activity per 14.6 s with the neon trio, 3268 ms per 13.3 s with only a BACKGROUND streaming card's stripes+pulses (switching away keeps its card animating at the same cost); paused → 8 ms. A single 8px animation costs the same as the three giant layers — per-frame pipeline overhead, not raster size. Frozen elements keep static state colors. See change: pause-decorative-fx-when-idle.
