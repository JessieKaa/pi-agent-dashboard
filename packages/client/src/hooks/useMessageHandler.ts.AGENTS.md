# useMessageHandler.ts — index

Dispatches `ServerToBrowserMessage` events to client state, including synchronous cursor/plugin/cache/loading side effects, coalesced replay/live ordering, pending-prompt settlement, and replay metadata. `history_backfill_result` handles `msg.error` first, splices events before exhaustion checks, and treats only `remainingGapCount === 0` as exhaustion; preserves holey-history gap/divider semantics, head-free `atFloor`, two-sided terminus, and `historyWindow`/`replayInFlight`/`historyGaps`/`historySpliceRev` metadata. `session_state_reset` and full replay reset clear stale `historyWindow`; unwindowed delta catch-up preserves it. Reset/replay carry only settled pending prompts; fresh `prompt_received` promotes sending to sent while raced events drop it. Attachment summaries use `imageCount`. Logs `replay:batch` (n, firstSeq, lastSeq, isLast, shouldReset, window) via gated `scrollDebugLog`.
