# session-sync.ts — index

Session register/replay/switch lifecycle. Exports `sendStateSync`, `replaySessionEntries`, `handleSessionChange`, and `consumeSpawnToken` (single-use read-and-scrub of `PI_DASHBOARD_SPAWN_TOKEN`). First register carries `registerReason:"spawn"`, `pid`, optional spawn token, dashboard-spawned state, and git-repo status; reconnects carry `"reattach"`. `handleSessionChange` sends one old-session `session_unregister` with `reason:"session_change"`, then registers and replays the new session. Sends commands, flows, models, providers, and related state. Delegates to `detectSessionSource`, `gatherGitInfo`, and `buildProviderCatalogue`. See changes: fix-tmux-session-shutdown-leak, fix-spawn-token-env-leak, reload-resume-lifecycle.
