# message-update-coalescer.ts — index

Bridge `message_update` coalescing state machine. Contiguous `text_start/delta/end` snapshots use a single-slot 50 ms fixed window; the last text snapshot wins only within a contiguous text run. `thinking_start/delta/end`, `toolcall_*`, and unknown subtypes flush pending text first and forward immediately, preserving source order while retaining thinking deltas. `messageStart(gen,key)` opens a message; `messageEnd(gen,key)` closes it after bridge flush; updates require the current open generation and stable role/timestamp key, so late same-generation events cannot refill `streamingText`. `flush()` is sync/idempotent; `clear(gen)` drops pending data, cancels the private timeout, and closes the lifecycle on session switch/shutdown/reload. Dependencies `send`, timer schedule/cancel, and clock are injectable. Bridge integration: flush at every non-message_update handler entry, before reconnect state sync/replay, and before subagent frames; clear on session switch/shutdown/reload. See change: coalesce-message-update-text-snapshots.
