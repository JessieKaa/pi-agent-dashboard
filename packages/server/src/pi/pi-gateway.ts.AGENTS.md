# pi-gateway.ts — index

WebSocket server for bridge extension connections. Routes `ExtensionToServerMessage` → `SessionManager`; pings every `WS_PING_INTERVAL` (60s), heartbeat timeout `HEARTBEAT_TIMEOUT` (180s). Exports `createPiGateway`, `PiGateway` (`start`/`stop`/`address`/`sendToSession`/`broadcast`/`findSessionByCwd`/`findSessionsByCwd`), `PiGatewayOptions`, `onSessionRegistered` callback (consumes pending spawn-attach intent). `findSessionsByCwd(cwd)` = plural prefix-match for folder-scoped reload (change: folder-resource-activation-toggle). See change: add-folder-task-checker-and-spawn-attach. Session owner guard maps sessionId → `{ws,generation}`; stale register/messages/unregister/close/heartbeat timers cannot mutate, delete, or unregister the current owner. `ws.on("close")` for current-owner `kind="automation"` sessions unregisters immediately (no reconnect grace) — headless one-shot runs never reconnect; every other session keeps the grace window. `closeSession()` only closes the owner socket; close handler owns lifecycle callbacks. See changes: finalize-automation-run-on-session-death, reload-resume-lifecycle.
